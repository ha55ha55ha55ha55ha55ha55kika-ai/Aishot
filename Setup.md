Настройка ScreenAI — где взять API-ключи
Приложение отправляет скриншот экрана выбранному AI-провайдеру. Ключ и модель
задаются в приложении: значок ⚙️ / настройки → выбираете провайдера → вставляете
ключ. Ключи хранятся локально на устройстве (SharedPreferences), никуда кроме
самого API-провайдера не уходят.
Почти у всех провайдеров ниже — платный API (отдельно от подписок вроде ChatGPT
Plus или Grok в X). Нужно завести аккаунт разработчика и пополнить баланс/привязать
карту, даже если сам чат-продукт у вас уже оплачен.
Gemini (Google)
Открыть https://aistudio.google.com/apikey
Войти под Google-аккаунтом → «Create API key».
Есть бесплатный лимit (rate-limited free tier) — для личного использования обычно достаточно.
Вставить ключ в поле «Gemini API ключ», модель — например gemini-2.5-flash (быстрая/дешёвая) или gemini-3.6-flash.
Claude (Anthropic)
Открыть https://console.anthropic.com/settings/keys
Зарегистрироваться/войти → «Create Key».
Пополнить баланс в разделе Billing (обычно нужен минимальный депозит, бесплатного тарифа нет).
Вставить ключ в поле «Claude API ключ», модель — например claude-sonnet-4-5.
OpenAI (GPT)
Открыть https://platform.openai.com/api-keys
Войти → «Create new secret key».
Пополнить баланс в Billing → Payment methods.
Ключ в поле «OpenAI API ключ», модель — например gpt-4o или gpt-5.
⚠️ Это отдельный аккаунт/баланс от ChatGPT Plus.
Grok (xAI)
Открыть https://console.x.ai/
Войти (можно через X/Twitter-аккаунт) → раздел API Keys → создать ключ.
Пополнить баланс — есть небольшой бесплатный кредит для новых аккаунтов.
Ключ в поле «Grok (xAI) API ключ», модель — например grok-4 или grok-2-vision-1212 (для картинок нужна vision-модель).
⚠️ Это отдельный API-ключ от подписки Grok/X Premium.
DeepSeek
Открыть https://platform.deepseek.com/api_keys
Зарегистрироваться → «Create new API key».
Пополнить баланс (цены очень низкие).
Ключ в поле «DeepSeek API ключ», модель — deepseek-chat или deepseek-reasoner.
⚠️ У DeepSeek пока нет публичной vision-модели — скриншот не отправляется,
AI отвечает только на текст промпта. Для анализа изображений выбирайте другого провайдера.
Mistral
Открыть https://console.mistral.ai/api-keys
Войти → «Create new key».
Пополнить баланс в Billing.
Ключ в поле «Mistral API ключ», модель — pixtral-large-latest (поддерживает изображения).
OpenRouter (один ключ — десятки моделей)
Удобно, если хотите переключаться между разными AI без создания отдельных
аккаунтов у каждого провайдера.
Открыть https://openrouter.ai/keys
Войти → «Create Key».
Пополнить баланс (https://openrouter.ai/settings/credits) либо использовать
бесплатные модели с пометкой :free в каталоге https://openrouter.ai/models.
Ключ в поле «OpenRouter API ключ», модель — строка вида провайдер/модель,
например:
anthropic/claude-3.5-sonnet
openai/gpt-4o
x-ai/grok-2-vision-1212
google/gemini-2.5-flash
Полный список моделей и их точные названия — на https://openrouter.ai/models.
Важно
Названия моделей у провайдеров периодически меняются/устаревают — если запрос
возвращает ошибку про неизвестную модель, проверьте актуальный ID в документации
провайдера и впишите его вручную в поле модели.
Ключи не логируются и не передаются никуда, кроме прямого HTTPS-запроса к API
выбранного провайдера.
